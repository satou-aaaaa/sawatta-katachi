# さわった形はどれ？（sawatta-katachi）

手でさわって分かった手がかり（とがった角の数・まっすぐなふち・平らな面・曲がった面・面の形・穴）を読み、目で見る形を4つの絵から選ぶ1日5問の学習ゲーム。正解したら2段目で「ほかの形ではないと分かる手がかり」も選ぶ。ときどき、モリヌークスの問いと、その答え合わせの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/sawatta-katachi/>

- モリヌークスの問い：生まれつき目が見えず、手でさわって球と立方体を見分けられるようになった人が、目が見えるようになってすぐ、さわる前に目だけで、どちらが球か言えるか。Molyneux の答えは「いいえ」で、Locke も同じ答えだと書いた。
  - John Locke, An Essay Concerning Human Understanding, 第2版（1694）, Book II, ch. 9, §8（本文は Stanford Encyclopedia of Philosophy "Molyneux's Problem" が引くものを読んだ。<https://plato.stanford.edu/entries/molyneux-problem/>）
- 答え合わせの研究：Held ら（2011）は、手術で見えるようになった5人（8〜17歳）を、手術から48時間のうちに調べた。2つの形から選ぶと、さわる→さわるは平均98%、見る→見るは92%当たったが、さわる→見るは58%だった。3人を調べ直すと、早い人で5日後には当たりが増えていた。
  - Richard Held, Yuri Ostrovsky, Beatrice de Gelder ほか, 2011, "The newly sighted fail to match seen with felt", Nature Neuroscience 14(5): 551–553（<https://doi.org/10.1038/nn.2795>）
- 形の問題の手がかりは、絵のもとの形（頂点と面）から数えた数で作っています。目の見え方のちがいで、人のよい悪いをくらべるゲームではありません。
